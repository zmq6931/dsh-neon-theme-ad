# 霓虹主题引擎 · dsh-neon-theme

DSH Web 界面的主题插件：**纯代码绘制的动态背景** + **免费壁纸库（实时预览、一键换）** + **会呼吸的霓虹窗口边框** + **发光输入框**，外加一个能按分类选、按分类自动轮换、按时间段自动切换的主题面板。

没有一张图片随包分发：十款皮肤全部用 CSS 渐变与动画画出来，任意分辨率都清晰；壁纸在你点选时才从免费壁纸库取回并缓存到本机。

## 安装

**桌面版**：设置 → 插件 → 添加插件，填入仓库地址：

```
https://github.com/zmq6931/dsh-neon-theme-ad
```

**CLI**：

```bash
dsh plugin --profile <你的 profile> add github:zmq6931/dsh-neon-theme-ad
```

装好后刷新页面（或重启 DSH），会话标题右侧会出现「✦ 霓虹主题」按钮；也可以从 设置 → 通用 → 霓虹主题引擎 打开。

> 需要带 Web 服务器的 DSH（桌面版或 `dsh web`）：壁纸代理（`/neon-theme/api/*`）和设置持久化跑在 Host 侧。

## 两个入口

- **会话标题右侧的「✦ 霓虹主题」按钮**：和 `Standard mode`、`1 subagent` 这些标识同一行（标题下方那排标签的上一行）。点它，设置面板直接出现在按钮左下；再点一次、点面板外、或按 Esc 关闭。
- **设置 → 通用 → 霓虹主题引擎**：一行说明加「打开面板」按钮，打开同一个面板。

## 功能

### 十款皮肤 / 五个分类

| 分类 | 皮肤 |
|---|---|
| 赛博霓虹 | 霓虹赛博、数据网格 |
| 星海宇宙 | 深空星海、星云漩涡 |
| 二次元幻想 | 樱花漫舞、夏夜花火 |
| 自然流光 | 极光天幕、晨曦微光 |
| 熔火余烬 | 熔火余烬、熔岩裂隙 |

- **点分类标签**：只过滤列表，并把自动轮换的候选范围限定在这个分类；不会自动改掉当前皮肤。
- **点皮肤卡片**：立即应用，界面下一帧就变。

### 分类自动选择（两种方式）

1. **自动轮换**：在当前分类里按固定间隔换一款（20 秒 / 30 秒 / 45 秒 / 1 分钟 / 2 分钟 / 5 分钟）。选「全部」就在十款里轮。
2. **按时间段**：清晨（05–09）极光天幕 → 白天（09–17）深空星海 → 黄昏（17–21）樱花漫舞 → 夜晚（21–05）霓虹赛博。每 30 秒检查一次，只在跨时段时切换。

**优先级**：时间段开启时以时间段为准，自动轮换暂停（面板里会写明）。手动点选的皮肤会保留到下一个时段开始，重启/刷新也不会被立刻覆盖。

### 壁纸（免费壁纸库 + 动态壁纸）

面板里有一段自动加载的壁纸库，先选 **图片** 还是 **动态视频**，再选分类。

**图片**（Wallhaven / Bing / Picsum）

| 分类 | 内容 |
|---|---|
| 精选 | Wallhaven 热门（≥2560×1440，SFW） |
| 人物 / 卡通 / 动物 | Wallhaven 对应分类或关键词热门 |
| 动漫 | Wallhaven 动漫分区热门 |
| 赛博 / 太空 / 风景 | Wallhaven 对应关键词热门 |
| 每日 | Bing 每日一图（最近 8 天，4K） |
| 随机 | Picsum 随机摄影 |

**动态视频**（Mixkit 免费视频，720p）

| 分类 | 内容 |
|---|---|
| 混合 | 自然 / 抽象 / 城市 / 科幻 / 粒子 / 太空 混排 |
| 动物 / 人物 / 卡通 | Mixkit 对应类别 |
| 城市 / 太空 | Mixkit 对应类别 |

**番剧**（Sakugabooru，动画作画片段归档，mp4/webm）

| 分类 | 内容 |
|---|---|
| 全网高光 | 全站评分最高的作画片段（不限定作品） |
| 鬼灭之刃 | 合并 TV + 无限列车 + 游郭 / 刀匠村 / 柱训练篇 五个标签，评分从高到低 |
| 火影忍者 / 海贼王 / 死神 / 咒术回战 | 对应番剧、按社区评分从高到低 |
| 进击的巨人 / 电锯人 / 葬送的芙莉莲 / 我的英雄学院 | 对应番剧、按社区评分从高到低 |
| 灌篮高手 | 只用三部剧场版（The First Slam Dunk + 剧场版 1/2），共 29 条彩色现代作画；90 年代黑白 TV 片段已剔除 |
| 网球王子 / 幽游白书 | 老番同样按评分排序 |
| 龙珠 | 合并 Z / 超 / 布罗利 / 神与神 / 复活的 F / 巴达克 / GT，评分最高的就是超赛变身与大战片段 |

> 番剧片段按 Sakugabooru 的社区评分（`order:score`）排序，前几页就是公认的高光/燃点剪辑；卡片右上角的小数字是评分。片段来自粉丝归档站 Sakugabooru，多为 640×480 / 854×480 的 TV 源，铺满 2K/4K 屏会偏软；每页 40 条，可以一直翻页。想换作品的话把名字告诉我，我加标签。

- 打开面板就自动拉第一批（列表本地缓存 30 分钟），**点缩略图立即换上**；动态卡片左下角有 ▶，鼠标悬停卡片内直接播 360p 预览，点一下变成真·动态壁纸。
- **播放列表（多选）**：动态视频卡片左上角的「+」把它加入播放列表（最多 12 个，再点取消），勾选后这些片段会**按顺序自动循环播放**；面板里会显示「播放列表 · N 个」和「清空列表」。图片壁纸不受影响。
- 「加载更多」在缩略图**下方**，每页 12 张、累计追加，右侧显示 `当前页 / 总页数`；加载多少留多少，不会被截断。
- 选图时会自动测量亮度，把偏暗的图提亮到舒适区间（1×–2.6×），面板里还有「壁纸亮度」滑块可以再微调。
- **播放优化**：视频请求走 HTTP Range（206）——已缓存的从本地切片秒开，未缓存的直接把 Range 透传到源站，不等整段下载完就能开播；播放列表会**预加载下一条**，切片段不再卡顿；6 秒无进展会自动重载一次，切回窗口时自动续播。
- 图片与视频都经本机代理取回并落盘缓存（`$DSH_HOME/neon-theme-cache`），第二次用同一张图/同一个视频是本地读取。
- 有壁纸时会自动把主界面（含 Windows 下整窗底衬）的不透明度压到很低，所以壁纸不会再被一层暗色盖住；「主界面不透明度」滑块仍可继续微调。
- 代理只允许白名单域名（wallhaven / bing / picsum / unsplash / mixkit），只接受 GET/HEAD，单张上限 24MB，不做任意转发。

### 边框与光效

- **整窗霓虹边框**：一圈呼吸光框 + 四角光角 + 一道沿边框旋转的流光 + 自上而下的扫描线。
- **输入框发光描边**：输入区域外圈同步呼吸。
- 光晕亮度、呼吸速度可调；扫描光可关；关掉「霓虹边框」后，扫描光/光晕/速度会自动置灰——它们只对边框生效。

### 主界面不透明度

「主界面不透明度」滑块控制主界面与侧栏面板的透明程度：**越低越透、动态背景越明显**；越高越接近实底界面，专注阅读时调高即可。浅色模式会自动抬高下限，避免次要文字对比度不足。

## 开关与持久化

- 面板底部的 **霓虹效果** 开关一键关闭背景、边框与输入框光效（`✦` 按钮与设置入口保留，方便再打开）。
- 设置会同时写两处：浏览器 `localStorage`（`dsh-neon-theme.settings.v1`，当前页面立即生效）和宿主文件 `$DSH_HOME/neon-theme-settings.json`（跨重启）。DSH 每次启动会换一个本机端口，页面来源变了 localStorage 就清空，所以靠宿主文件保证换端口/重启后皮肤和壁纸还在。
- 「恢复默认」回到初始配置。

## 兼容与性能

- 只通过官方 `dsh.client` 声明 + bundle patch 挂载，不修改 DSH 本体；停用插件后注入的样式、根元素属性与自定义属性都会被清理。
- 背景动画只改 `transform` / `opacity`，交给合成层，不触发布局。
- 系统开启「减少动态效果」时，所有动画与过渡停止（面板里会有提示），但皮肤轮换与时段切换仍会执行——它们只是换配色，没有运动。

## 已知限制

- **壁纸需要联网**（首次加载列表、图片与视频）；接口不可用时自动回退到内置的 8 张 Wallhaven 精选，界面不会空着。动态视频首次播放要下载 720p 文件（每个约 3–6MB），之后走本地缓存。
- 壁纸图片/视频版权归各站点与原作者（Wallhaven 上传者 / Microsoft Bing / Picsum 的 Unsplash 作者 / Mixkit），本插件只在本机取回缓存用于个人界面装饰，不重新分发。缓存目录最多保留 80 个文件，超出按最旧删除。
- 背景靠 `body` 伪元素绘制，并通过覆盖 `--dsw-alias-bg-base`、`--dsw-specific-sidebar-fill` 让主界面半透明；如果将来的 DSH 版本改了这两个 token 的名字，背景会不可见（边框与面板不受影响）。
- 这两个 token 是全站共用的，所以菜单、输入框、代码块底衬也会一起变半透明，这是「玻璃界面」的代价；调高不透明度即可恢复。
- **和其它主题插件会互相抢背景**：本机还装着 `dsh-anime-theme` 之类的壁纸主题插件时，两者的背景层、面板透明度和边框会叠加甚至互相覆盖。建议只启用一个：在 设置 → 插件 → 插件列表 里停用其中一个。
- 输入框描边画在 `[data-composer-seat]` 上，是输入区外圈的光环，不是逐像素贴合输入框圆角。
- Chat / Trajectory 那条标签行本身没有留给插件的内联插槽（`…` 是视图溢出菜单、最右边的 ⛶ 是右栏展开按钮），所以入口做在标题行的官方 action 区；如果你更想要它落在标签行里，需要按坐标浮动定位，DSH 升级后可能失效。

## 开发

